# Звуки проекта

Все WAV созданы оригинальным скриптом `tools/generate_audio.py`. Чужие аудиозаписи, мелодии и сэмплы не использовались. Формат: mono PCM16, 22050 Гц. Генерация детерминирована; скрипт печатает длительность и максимальную амплитуду каждого файла.

- `jump.wav`, `land.wav` — короткие сигналы прыжка и приземления.
- `splash.wav` — фильтрованный шум и низкий удар при падении в воду.
- `checkpoint.wav`, `victory.wav` — короткие последовательности нот.
- `river.wav` — 5 секунд сглаженного шума для негромкого фона реки.

Повторная генерация из корня проекта (используется Python, поставляемый с Blender; зависимости устанавливать не нужно):

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.3\blender.exe' --background --python tools/generate_audio.py
```

Фон зацикливается в Godot. Громкости и подключение событий задаются в `scripts/feedback.gd`. Выключатель «Звук» в паузе управляет общей шиной и сохраняет состояние при перезапуске уровня в текущем запуске приложения.
