## Woodland atlas — исходная запись

Оригинальная растровая текстура создана встроенным инструментом imagegen, без изображений-референсов и без материалов из The Hobbit. Файл: `woodland-atlas-v1.png`. Четыре квадранта: трава/земля, древесина, замшелый камень, листва. Используется реальными материалами Godot, не является подменой игрового кадра. Источники коммерческой игры хранятся отдельно в исключённом artifacts/ и служат только сравнением.

Точный промпт генерации:

```text
Use case: stylized-concept. Asset type: original hand-painted diffuse texture atlas for a small 3D fantasy adventure game, intended for mapping onto actual meshes, NOT a concept scene. Create ONE square 1024x1024 image divided into exactly FOUR equal square texture panels in a strict 2 by 2 grid with NO borders, margins, text, labels, perspective, objects, lighting highlights, vignette or cast shadows. Upper-left quarter: seamless mossy grass and earth ground, painterly olive and fern greens, ochre soil specks and tiny clustered short blades, medium-scale broad mottling, rich subdued woodland colors. Upper-right quarter: seamless weathered oak timber diffuse surface, grain running vertically, wavy streaks and occasional small knots, dark umber crevices, warm desaturated brown, readable at 256 pixels, no regular plank joins. Lower-left quarter: seamless mossy grey river cliff rock diffuse, large interlocking irregular slate shapes with dark cracks, muted grey-green and ochre edge wear, painterly soft shading baked into crevices, no photorealistic noise. Lower-right quarter: seamless canopy foliage diffuse, dense overlapping broad oak leaves, small leaf silhouettes clustered into readable painterly masses, deep shadow-green gaps, moss/olive leaf highlights, no black holes or alpha. Visual language of polished early-2000s console fantasy adventure hand-painted textures, soft brushwork with strong value structure, organic details, deliberately non-photographic. Each quarter independently tiles edge-to-edge and fills its entire quarter. The four quarters meet exactly at x=512 and y=512. Absolutely no logos or any existing game artwork.
```

## Категории материалов героя

Генератор сохраняет в альфа-канале COLOR_0 разметку: кожа ~0.12, фурнитура ~0.35, ткани ~0.55, волосы ~0.92. Это данные для выбора участка атласа; игровой shader не использует их как прозрачность. После импорта Godot значения проверены на настоящих Mesh arrays, а smoke требует отдельных категорий кожи и ткани. Изначально отсутствующая связь Vertex Color Alpha с BSDF Alpha заставляла exporter записывать1.0 везде; этот дефект исправлен в исходнике генератора.

Шейдеры используют оригинальные цвета вершин и рисунок атласа, затем освещение сцены. Для Compatibility нормировка учитывает sRGB-вывод; линейный вариант оставлен отдельно. Сам по себе импорт PNG или успешный headless-запуск не доказывает художественный результат: его принимают по реальным кадрам в doc/gauntlet-graphics-review.md.
